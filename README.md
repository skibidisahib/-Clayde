# Content Rewards Automation Platform

A fully automated content monetization system that finds content opportunities, creates clips from existing content, posts to social media, and tracks earnings.

## Features

🤖 **Fully Automated**
- Scrapes content reward opportunities from multiple sources
- Automatically finds matching creators
- Generates optimized video clips (15s, 30s, 60s)
- Posts to Instagram, TikTok, and YouTube
- Tracks views and calculates earnings

💰 **Monetization**
- Pay-per-view model ($1 per 1,000 views)
- Automatic earnings tracking
- Weekly payouts (minimum $10)
- Real-time dashboard stats

🎬 **Content Management**
- Video editing and optimization
- Watermark and overlay support
- Multi-format clip generation
- Social media optimization

## System Architecture

```
Content Rewards Platform
├── Reward Scraper (finds opportunities every 6 hours)
├── Creator Finder (matches creators to rewards)
├── Clip Generator (creates 15s, 30s, 60s clips)
├── Social Media Poster (auto-posts to IG, TikTok, YouTube)
└── Earnings Tracker (calculates $$ every 2 hours)
```

## Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
```bash
cp .env.example .env
```

Edit `.env` and add:
- Instagram API token & user ID
- TikTok API token
- YouTube API token
- JWT secret key

### 3. Start the Server
```bash
npm start
```

Server runs on `http://localhost:5000`

## API Endpoints

### Authentication
- `POST /api/auth/register` - Register new user
- `POST /api/auth/login` - Login user

### Rewards
- `GET /api/rewards` - List all available rewards
- `GET /api/rewards/:id` - Get reward details
- `POST /api/rewards/:id/create-campaign` - Create campaign for reward

### Campaigns
- `GET /api/campaigns` - List user's campaigns
- `GET /api/campaigns/:id` - Get campaign details
- `PATCH /api/campaigns/:id` - Update campaign status
- `DELETE /api/campaigns/:id` - Delete campaign

### Earnings
- `GET /api/earnings/dashboard` - Get earnings summary
- `GET /api/earnings/pending` - Get pending earnings
- `GET /api/earnings/history` - Get earnings history
- `POST /api/earnings/request-payout` - Request payout (min $10)

## Automation Workflow

### Every 6 Hours
1. Scrape content reward opportunities from web
2. Save to database with payment details

### Every 4 Hours
1. Find campaigns in "draft" status
2. Search for matching creators
3. Generate 3 video clips (15s, 30s, 60s)
4. Auto-post to Instagram, TikTok, YouTube

### Every 2 Hours
1. Check view counts on all posted content
2. Calculate earnings based on views × payment rate
3. Update earnings in database

### Every Sunday at Midnight
1. Process pending payouts (minimum $10)
2. Mark earnings as "paid"
3. Send payout notifications

```javascript
const REWARD_SOURCES = [
  'https://www.whop.com/rewards',

```

### Adjust Payment Rates
Modify `payment_per_1k_views` in database:
```bash
sqlite3 data/rewards.db
UPDATE rewards SET payment_per_1k_views = 2.50 WHERE id = 1;
```

### Change Automation Schedule
Edit `server/automation/engine.js`:
```javascript
// Run every 2 hours instead of 6
cron.schedule('0 */2 * * *', async () => { ... });
```

## Troubleshooting

**No views being tracked:**
- Check API tokens are valid in `.env`
- Verify posts were published successfully

**Clips not generating:**
- Ensure FFmpeg is installed: `ffmpeg -version`
- Check output directory permissions

**Payouts failing:**
- Minimum payout is $10
- Check Stripe credentials if configured
